## Status meaning

- **Implemented**: the transcribed limitation has operative end-to-end implementation and evidence; this status would not authenticate patent provenance.
- **Partial**: reusable mechanics or a named capability exist, but substantive or deployment elements remain absent.
- **Missing**: no operative implementation of the claim's central capability exists.

No claim is recorded as implemented end to end. Claims 5 and 20 have
implementation-defined mechanical V2 contracts integrated into the public
foundational request path. Claims 1, 2 and 16 have isolated
implementation-defined mechanical V2 contracts. All remain Partial against the
provisional transcriptions because external authorities, substantive evidence
or deployment systems are absent. Claims 3 and 14 remain Missing.
